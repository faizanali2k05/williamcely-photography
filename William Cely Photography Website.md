# William Cely Photography Website

This is a professional, responsive portfolio website built with HTML5, CSS3, Bootstrap 5, and JavaScript.

## Features
- **Modern Design:** Inspired by Carlota Nurse Photography, with a clean and elegant aesthetic.
- **Responsive:** Fully optimized for mobile, tablet, and desktop.
- **Animations:** Smooth scroll and reveal-on-scroll animations using AOS.
- **Portfolio Categories:** Dedicated sections for Maternity, Weddings, Quinceañeras, and more.
- **Contact Form:** Ready-to-use contact form layout.

## How to use
1. **Images:** I have used placeholder paths in the `index.html`. You need to place your downloaded images in the `images/` folder and name them as follows (or update the paths in `index.html`):
   - `hero-bg.jpg` (Hero section background)
   - `maternity.jpg`
   - `quinceanera.jpg`
   - `wedding.jpg`
   - `birthday.jpg`
   - `couples.jpg`
   - `newborn.jpg`
   - `about-william.jpg` (Photo of William)
   - `insta-1.jpg` to `insta-6.jpg` (Instagram feed samples)

2. **Customization:**
   - Open `index.html` to update the text content if needed.
   - Open `css/style.css` to change colors or fonts.

## Deployment
Simply upload the entire folder to your hosting provider (e.g., Netlify, Vercel, or traditional FTP).
